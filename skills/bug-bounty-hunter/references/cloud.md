# Cloud and infrastructure exposure

Inventory only in-scope cloud assets, storage, CI/CD, deployment metadata, DNS, TLS, and public service configuration. Validate access with public, non-sensitive metadata or a dedicated test object. Do not access metadata services, private buckets, credentials, or control-plane actions.

Record provider, asset owner, exposure path, authentication boundary, and remediation such as private-by-default policy, least privilege, rotation, and network controls.
