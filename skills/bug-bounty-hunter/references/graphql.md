# GraphQL

When GraphQL is detected, map endpoint, operations, variables, types, aliases, fragments, batching, persisted queries, introspection policy, and error behavior. Load only the schema/operations needed for the authorized test.

Test object- and field-level authorization with synthetic identities, query depth/complexity controls, mutation state transitions, and transport differences. Do not dump the full schema or data when a minimal query suffices. Introspection exposure alone is context-dependent; connect it to sensitive schema or missing authorization.
